# Third-party notices

This plugin follows workflow and validation patterns derived from the MIT-licensed
`earthtojake/text-to-cad` CAD Skills project. It does not import code from an
installed plugin cache at runtime.

Optional adapters integrate with separately installed projects:

- Open CASCADE Technology through `cadquery-ocp`
- ezdxf
- eDOCr2

Review each dependency and model-weight license before commercial distribution.
